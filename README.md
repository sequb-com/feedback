# Sequb feedback

The public channel for feedback on [Sequb](https://sequb.com): deterministic financial and calendar
calculations for AI agents, with signed, independently verifiable calculation evidence.

Use it to:

- **ask for a capability**: a tool, an option or a market Sequb does not cover yet;
- **ask for a new domain**: a kind of calculation Sequb does not do at all;
- **report a calculation question or defect**: a result you believe differs from the rule it cites.

Requests here are one of the inputs Sequb uses to decide what to build next.

## Never post private data

This repository is **public**. Do not post loan details, customer data, personal information, API
keys or evidence packages that contain any of these. Describe the case with made-up values that
reproduce it. Sequb itself never logs request or response bodies.

## Security issues

Do **not** report vulnerabilities in an issue. Use **Security → Report a vulnerability** on this
repository, which reaches the maintainers privately.

## What Sequb claims

Sequb computes under a named, versioned, reviewed rule set for a declared scenario. It does not give
legal, credit or compliance advice, and a feedback thread is not a support contract.
